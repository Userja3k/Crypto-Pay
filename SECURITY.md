# Security Policy

## Reporting a Vulnerability

We take the security of Crypto-Pay seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not open a public issue.**
2. Send an email to security@crypto-pay.cd (placeholder) with a detailed description of the vulnerability.
3. Include steps to reproduce the issue.

We will acknowledge your report within 48 hours and provide a timeline for a fix.

## Supported Versions

We only provide security updates for the latest stable version of Crypto-Pay.
